START UP - an idle clicker game about a tech startup
CS 401 class project

HOW TO RUN
  Double-click index.html (or drag it into Chrome, Firefox, Edge or Safari).
  Nothing needs to be installed. There is no build step and no server.
  An internet connection is only used to load the pixel font. Without it the
  game still works and uses a plain fallback font.

HOW TO PLAY
  Click the Fix a Bug row to start it. When the bar fills up you get paid.

FILES
  index.html   The page itself. Loads the font, style.css and the scripts.
  style.css    Colors, layout and the pixel look.
  game.js      The game: clicking tasks, the timer, paying the player and
               updating the screen.
  readme.txt   This file.
  dev-notes.md A log of problems and design changes while building the game.
  test-checklist.md  Step-by-step manual tests for each layer.
